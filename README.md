# Gnomo CWB - Portal de Links & Projetos

Página pessoal e central de links de Gnomo CWB (Curitiba, BR).

## Estrutura do Projeto
- `index.html`: Página principal com navegação fluida, seções retráteis e design responsivo.
- `vercel.json`: Configurações otimizadas para deploy na Vercel.
- `backup/`: Cópias de segurança de versões anteriores.

## Deploy na Vercel
Este projeto é 100% estático (HTML, CSS e JS puros), sem dependências nem etapa de compilação/build.
